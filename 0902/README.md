# PLC와 로봇 간 CC-Link 통신 실습 정리

## 1. 실습 개요

이번 실습에서는 **PLC와 로봇을 CC-Link로 연결**하고, PLC에서 발생한 버튼 입력 신호를 로봇에 전달하여 동작을 제어하는 방법을 학습했다.

실습의 기본 흐름은 다음과 같다.

```text
버튼 입력
   ↓
PLC 내부 비트 ON
   ↓
CC-Link 통신
   ↓
로봇 입력 신호 ON
   ↓
로봇 동작 실행
```

즉, PLC에서 버튼을 누르면 해당 신호가 CC-Link를 통해 로봇으로 전달되고, 로봇은 전달받은 신호에 따라 지정된 동작을 수행한다.

---

## 2. CC-Link란?

**CC-Link(Control & Communication Link)**는 공장 자동화 환경에서 PLC와 각종 산업용 장비를 연결하기 위한 산업용 네트워크이다.

주로 다음과 같은 장비 사이에서 사용된다.

* PLC
* 로봇
* Remote I/O
* 인버터
* 서보 시스템
* 센서 및 액추에이터

CC-Link를 사용하면 각 장치의 입력과 출력을 개별 배선으로 모두 연결하지 않고, 통신 네트워크를 통해 여러 개의 신호를 주고받을 수 있다.

특히 다음과 같은 ON/OFF 신호를 전달하는 데 적합하다.

* START
* STOP
* READY
* ERROR
* MOVE DONE
* RESET

---

## 3. 실습에서 CC-Link를 사용한 이유

PLC와 로봇은 Ethernet을 이용해서도 연결할 수 있다.

하지만 이번 실습에서는 PLC의 버튼 입력과 같은 **비트 단위의 제어 신호를 로봇에 전달하는 것**이 목적이었기 때문에 CC-Link를 사용했다.

예를 들어 PLC에서 START 버튼을 누르면 다음과 같은 과정으로 동작한다.

```text
START 버튼 ON
        ↓
PLC 내부 디바이스 ON
        ↓
CC-Link를 통해 신호 전달
        ↓
로봇의 START 입력 ON
        ↓
로봇 프로그램 실행
```

CC-Link에서는 PLC와 로봇의 입출력 데이터를 서로 대응시켜 사용할 수 있기 때문에, PLC 입장에서는 로봇의 신호도 일반적인 I/O 신호처럼 비교적 직관적으로 다룰 수 있다.

따라서 이번 실습의 목적은 단순히 "CC-Link에서는 버튼을 사용할 수 있기 때문"이 아니라,

> **PLC에서 발생한 ON/OFF 제어 신호를 로봇에 간단하고 안정적으로 전달하기 위해 CC-Link를 사용한 것**

이라고 이해하는 것이 정확하다.

---

## 4. Ethernet과의 차이

Ethernet 역시 PLC와 로봇 사이의 통신에 사용할 수 있다.

하지만 일반적인 Ethernet 통신에서는 단순히 LAN 케이블만 연결한다고 통신이 이루어지는 것은 아니다.

통신 방식에 따라 다음과 같은 설정이 필요할 수 있다.

* IP Address 설정
* Port 설정
* TCP/IP 또는 UDP 설정
* 통신 프로토콜 설정
* 송수신 데이터 형식 정의
* PLC 및 로봇 프로그램 작성

예를 들어 Ethernet 기반 TCP/IP 통신에서는 다음과 같은 구조가 될 수 있다.

```text
PLC
 ↓
통신 데이터 생성
 ↓
TCP/IP Socket 통신
 ↓
Ethernet
 ↓
로봇
 ↓
수신 데이터 분석
 ↓
동작 실행
```

반면 CC-Link는 PLC와 로봇 사이의 비트 및 워드 데이터를 미리 매핑하여 사용할 수 있기 때문에 단순한 제어 신호를 주고받는 데 편리하다.

---

## 5. CC-Link와 Ethernet 비교

| 구분       | CC-Link                  | Ethernet                 |
| -------- | ------------------------ | ------------------------ |
| 주요 목적    | 산업 장비 제어                 | 범용 데이터 통신                |
| 주요 사용 장비 | PLC, 로봇, 서보, 인버터, I/O    | PLC, PC, HMI, 서버, 로봇     |
| 데이터 사용   | Bit / Word 단위 제어 데이터     | 다양한 형식의 데이터              |
| 제어 신호 처리 | 비교적 간단                   | 프로토콜에 따라 추가 설정 필요        |
| 대표 신호    | START, STOP, READY, DONE | 명령 데이터, 상태 데이터 등         |
| 네트워크 설정  | CC-Link 설정 및 데이터 매핑      | IP, Port, Protocol 등의 설정 |
| 특징       | 산업용 실시간 제어에 적합           | 범용성과 확장성이 높음             |

## 6. PLC-로봇 신호 교환 예시

PLC와 로봇을 연동할 때는 일반적으로 한 방향으로만 신호를 보내는 것이 아니라 서로 상태를 주고받는다.

### PLC → Robot

```text
START
STOP
RESET
PROGRAM SELECT
POSITION SELECT
```

PLC에서 로봇에게 동작 명령을 전달한다.

### Robot → PLC

```text
READY
BUSY
MOVE DONE
ERROR
```

로봇에서는 현재 상태나 동작 완료 여부를 PLC로 전달한다.

전체적인 제어 흐름은 다음과 같이 구성할 수 있다.

```text
[PLC]

START 버튼 ON
    │
    ▼
CC-Link
    │
    ▼
[ROBOT]

동작 시작
    │
    ▼
동작 수행
    │
    ▼
MOVE DONE ON
    │
    ▼
CC-Link
    │
    ▼
[PLC]

동작 완료 확인
```

이와 같이 PLC가 로봇에게 명령을 전달하고, 로봇이 다시 자신의 상태를 PLC에 전달하면서 자동화 시스템이 동작한다.

## 7. CC-Link의 장점

### 1) 배선 감소

각 신호마다 개별적으로 전선을 연결하는 방식이라면 START, STOP, READY, ERROR 등의 신호마다 별도의 배선이 필요하다.

CC-Link를 사용하면 하나의 네트워크를 통해 여러 개의 데이터를 전달할 수 있어 배선을 줄일 수 있다.

### 2) Bit 단위 제어가 편리함

PLC와 로봇 사이에서 사용하는 제어 신호는 대부분 ON/OFF 형태이다.

CC-Link에서는 이러한 신호를 Bit 단위 데이터로 쉽게 주고받을 수 있다.

### 3) 산업용 제어에 적합

공장 자동화에서는 장치가 일정한 주기로 데이터를 주고받고 빠르게 상태를 확인해야 한다.

CC-Link는 이러한 산업용 제어 환경을 고려하여 만들어진 네트워크이다.

### 4) 여러 장비 연결 가능

PLC 한 대에 여러 개의 장비를 네트워크로 연결할 수 있다.

```text
              ┌─ Robot
              │
PLC ─ CC-Link ├─ Remote I/O
              │
              ├─ Inverter
              │
              └─ Servo
```
